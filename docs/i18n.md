# Internacionalização (i18n)

Este projeto utiliza **react-i18next** para internacionalização, com suporte para múltiplos idiomas.

## Estrutura de Arquivos

```
src/
  locales/
    pt-BR/
      common.json       # Traduções comuns (ações, status, paginação)
      errors.json       # Mensagens de erro
      classroom.json    # Traduções específicas do módulo classroom
      index.ts          # Exporta todas as traduções de pt-BR
    en-US/
      common.json
      errors.json
      classroom.json
      index.ts          # Exporta todas as traduções de en-US
    index.ts            # Configuração principal dos idiomas
  i18n.ts               # Configuração do i18next
```

## Idiomas Disponíveis

- **pt-BR** (Português Brasil) - Idioma padrão
- **en-US** (Inglês Americano)

## Como Usar

### 1. Usando traduções em componentes

```tsx
import { useTranslation } from "react-i18next";

export const MyComponent = () => {
  const { t } = useTranslation();

  return (
    <div>
      <h1>{t("classroom.title")}</h1>
      <button>{t("common.actions.save")}</button>
    </div>
  );
};
```

### 2. Traduções com interpolação de variáveis

```tsx
// No arquivo de tradução (classroom.json):
{
  "delete": {
    "message": "Tem certeza que deseja excluir a sala {{name}}?"
  }
}

// No componente:
const message = t("classroom.delete.message", { name: "Sala 101" });
// Resultado: "Tem certeza que deseja excluir a sala Sala 101?"
```

### 3. Componente de troca de idioma

O projeto inclui um componente `LanguageSwitcher` que pode ser adicionado ao menu ou qualquer outra parte da aplicação:

```tsx
import { LanguageSwitcher } from "./components/LanguageSwitcher";

// Use no seu componente:
<LanguageSwitcher />
```

## Organização das Traduções

### common.json
Traduções compartilhadas entre todos os módulos:
- **actions**: Ações comuns (adicionar, editar, excluir, etc.)
- **status**: Estados de loading e processamento
- **pagination**: Textos de paginação
- **common**: Termos genéricos reutilizáveis

### errors.json
Mensagens de erro gerais e específicas de cada módulo.

### [modulo].json
Traduções específicas de cada módulo (ex: classroom.json para a página de salas).

## Adicionando Novos Idiomas

1. Crie uma nova pasta em `src/locales/` (ex: `es-ES/`)
2. Crie os arquivos JSON necessários (`common.json`, `errors.json`, etc.)
3. Crie o `index.ts` exportando as traduções
4. Adicione o idioma em `src/locales/index.ts`:

```ts
import esES from "./es-ES";

export const resources = {
  "pt-BR": { translation: ptBR },
  "en-US": { translation: enUS },
  "es-ES": { translation: esES }, // Novo idioma
};

export const availableLanguages = ["pt-BR", "en-US", "es-ES"];
```

5. Atualize o componente `LanguageSwitcher` com o label do novo idioma.

## Adicionando Novas Traduções

Para adicionar traduções de um novo módulo:

1. Crie `[modulo].json` em cada pasta de idioma
2. Adicione as traduções correspondentes
3. Importe e exporte no `index.ts` de cada idioma:

```ts
import myModule from "./myModule.json";

export default {
  common,
  errors,
  classroom,
  myModule, // Novo módulo
};
```

4. Use no componente:
```tsx
{t("myModule.someKey")}
```

## Detecção Automática de Idioma

O sistema detecta automaticamente o idioma do navegador do usuário. A ordem de detecção é:
1. Idioma salvo no `localStorage`
2. Idioma do navegador
3. Idioma padrão (pt-BR)

O idioma escolhido é automaticamente salvo no `localStorage` para persistência.
